# Student Management System API

A Spring Boot REST API for managing student records.

## Technologies
- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven

## Features
- Create Student
- Get All Students
- Get Student By ID
- Update Student
- Delete Student
- Exception Handling
- Validation

## Endpoints

POST /students

GET /students

GET /students/{id}

PUT /students/{id}

DELETE /students/{id}
